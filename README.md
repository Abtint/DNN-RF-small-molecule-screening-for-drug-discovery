DNN and RF Models for Small-Molecule Screening

This repository contains deep neural network (DNN) and random forest (RF) models developed for small-molecule screening in drug discovery.

Before using the notebooks as a reference or adapting the workflow to another dataset, see the Methods section of the paper listed under Citation, particularly Section 2.1, Activity Dataset, for details on dataset preparation and model development.
